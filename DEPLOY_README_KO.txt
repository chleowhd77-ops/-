축구 분석 웹 V5 최종 보강판
============================

이번 버전에서 달라지는 점
1. 베트맨 프로토 축구 경기를 기본 30개로 자르지 않고 전부 수집합니다.
2. 배당이 잠시 비어도 경기 자체는 화면에서 사라지지 않습니다.
3. 실시간 경기판을 한 번 조회해 여러 경기를 연결하므로 API 사용량을 줄입니다.
4. 같은 실제 경기가 프로토와 승무패 14경기에 함께 있어도 각각 스코어를 표시합니다.
5. 팀 이름은 검증된 팀 ID와 안전한 영문 별칭으로 연결해 잘못된 마크 매칭을 줄입니다.
6. API가 소진되면 계속 호출하지 않고 기존 정상 캐시와 베트맨 자료로 동작합니다.
7. API 날짜가 바뀌면 보호 모드가 자동 해제됩니다.
8. 라이브 이벤트 상세 조회는 기본으로 끄고 점수 조회용 한도를 남깁니다.
9. 기존 분석 시스템(최근전적, 홈/원정, 상대전적, 휴식일, 날씨, 더비,
   감독, 심판, 핵심선수 결장, 선발 라인업, 역배 탐지, 포아송 계산)은 유지됩니다.
10. 강한 근거가 있는 경기는 70%대 확률이 가능하지만, 데이터가 부족한 경기의
    숫자를 억지로 높이지 않도록 과신 방지 보정을 적용합니다.

  초기화 뒤부터 정상 보강됩니다. 그 전까지 기존 캐시는 유지됩니다.
